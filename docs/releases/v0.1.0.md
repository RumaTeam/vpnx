# VPNX 0.1.0 — Virtual Pinball anywhere

Visual Pinball for the Nintendo Switch: play your own `.vpx` tables, with their PinMAME romsets, natively on the console.

## Highlights
- **Vulkan renderer** (nxvk): about 28 fps on a heavy table in handheld mode, with the physics at 1000 Hz.
- **PinMAME romsets** with sound, and the **ScoreView DMD** drawn in a corner of the playfield (it follows the Cabinet view).
- **Built-in frontend**: list and grid with the table's screenshot, favourites, time played, options and a controls help. English (US) and Português (Brasil).
- **Cabinet view** with the top of the table to the right, and a **HOME-menu forwarder** so it always starts in Application mode.
- Works as a runner of [Ruma](https://github.com/RumaTeam/ruma).

## Install
1. Extract `vpnx-0.1.0.zip` at the **root of your SD card**.
2. Put your tables in `sdmc:/roms/vpx/` and each romset in a `pinmame` folder next to its table (for example `sdmc:/roms/vpx/pinmame/<romset>.zip`).
3. Open **VPNX** from the homebrew menu. Opened through the album (applet mode) it offers to create a HOME icon that opens it in Application mode: say yes.

Screenshots go in `sdmc:/switch/vpnx/media/<table file name>.jpg|png`; the game saves one the first time you close a table.

## Controls
`A` launch ball · `B` start · `X` credit · `ZL/L` and `ZR/R` flippers · right stick plunger · left stick nudge · `−` in-game menu · `+` close the table.
In the frontend: D-pad moves, `A` plays, `X` favourite, `Y` list/grid, `+` options (language, camera view, DMD, clocks, controls help), `B` quits.
